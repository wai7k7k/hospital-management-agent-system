# 知识库数据目录

此目录用于存储知识库相关的数据文件。

## 目录结构

```
data/
├── documents/          # 原始文档存储
│   ├── triage/        # 分诊知识文档
│   ├── medication/    # 用药知识文档
│   ├── hospital/      # 医院信息文档
│   └── general/       # 通用医学知识文档
├── processed/         # 处理后的文档
└── embeddings/        # 嵌入向量缓存
```

## 使用说明

1. 将原始文档放入对应的子目录
2. 通过API上传文档到知识库
3. 系统会自动处理和向量化文档
4. 向量数据存储在Pinecone中

## 支持的文档格式

- .txt - 纯文本文件
- .md - Markdown文件
- .json - JSON格式文件
- .csv - CSV格式文件

## 注意事项

- 文档大小建议不超过10MB
- 文本编码建议使用UTF-8
- 避免包含特殊字符和格式
