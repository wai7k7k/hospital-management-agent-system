# 患者建档入口补充

## 问题

前端已有患者自助注册页面和新增患者接口，但路由表没有注册 `/patientRegister`，后台侧边栏也没有患者建档入口，因此页面无法正常进入或供工作人员使用。

## 处理

- 恢复 `/patientRegister` 公共页面路由，保证原有注册链接可以打开。
- 新增后台“患者建档”页面和侧边栏入口 `/patient-archive/create`。
- 复用现有 `POST /customer-serv/patient` 接口，并在提交前校验姓名、18 位身份证号、11 位手机号、性别和出生日期。
- 建档成功后明确提示患者登录账号为手机号，初始密码为 `123456`。

## 验证

使用 Vue 生产构建完成编译。构建中仅出现项目原有的 `register` 导出和包体积警告，本次新增页面及路由没有编译错误。
